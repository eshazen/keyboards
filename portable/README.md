# Portable keyboard

Thinking about a portable version of the keyboard, possibly bluetooth.
Possible parts:

* Gateron KS33 low-profile switches
* Gateron low-profile keycap set

Messing with some 3D models it looks as if the total height above
the PCB is about 12mm and about 3mm to bottom of the pins/pegs,
so total around 15mm high.

60% keyboard is 11.25 x 3.75.

## Portable system?

Looking at a full portable system.  Some SBC options:

### RPi 5

Built-in Wifi, but need a hat for eMMC storage.

### Orange Pi

Many confusing pi 5 options.  Some have 2x eMMC
so can do WiFi and storage.  Relatively expensive. 

### ARM OS options

* https://dietpi.com/ - maybe try on a VM?
